Built natively for

macOS

Written in Swift with Apple's own frameworks. It follows dark mode, launches at login, updates itself from inside the app, and stays tiny. No Electron, no web view, nothing running that doesn't need to.

Download for Mac

Up and running in a minute

No account, no App Store, no licence key. Pick whichever route you like.

curl -fsSL https://lookaway.yoelgal.com/install.sh | bash
  1. Open Terminal. Press ⌘ Space, type Terminal, and hit Return.
  2. Paste and run. Paste the command with ⌘ V and press Return.
  3. Look up. The mascot appears in your menu bar. That's your break timer.

Why Terminal? The app isn't notarised by Apple, and files fetched with curl aren't quarantined, so it opens without a Gatekeeper warning. Read install.sh before you run it.

brew install --cask yoelgal/tap/openlookaway

Installs from the yoelgal/homebrew-tap cask. Update later with brew upgrade --cask openlookaway.

Download OpenLookAway.zip

Unzip it and drag OpenLookAway into Applications. Because the app isn't notarised, macOS stops it the first time:

  1. Open the app once and dismiss the warning.
  2. Go to System Settings → Privacy & Security.
  3. Scroll down and click Open Anyway, then confirm.

Rather skip those steps? The Terminal route avoids the warning entirely.

Questions, answered

Why a Terminal command instead of a normal download?

Apple charges a yearly fee to notarise apps. Without notarisation, anything downloaded through a browser is flagged by Gatekeeper and needs a detour through System Settings. Files fetched with curl aren't flagged, so the one-liner installs and opens the app with no warning. The app is still code-signed (ad hoc), so macOS notices if it's been tampered with.

Is piping a script into bash safe?

It's a fair thing to ask. Read the script first; it's short. It downloads the latest release from GitHub, moves it into Applications, and opens it. It never uses sudo and installs nothing else. Everything is open source and releases are built by GitHub Actions straight from the code.

Does it collect any data?

No. There's no account, no analytics, and no tracking. The only network request it makes is checking GitHub for new versions. Your stats stay on your Mac.

How do I update or uninstall it?

To update, use Check for Updates… in the app, run the install command again, or brew upgrade --cask openlookaway. To uninstall, quit it from the menu bar panel and drag OpenLookAway from Applications to the Bin (or brew uninstall --cask openlookaway).

Which Macs does it run on?

Any Mac on macOS 14 Sonoma or later, Apple silicon or Intel.

Is this the official LookAway?

No. OpenLookAway is an independent open-source project inspired by LookAway, a polished paid app with extras such as iPhone sync and automations. If you want those, support the original.
