Using Homebrew? brew install --cask yoelgal/tap/openlookaway

Rather download it? Grab OpenLookAway.zip, unzip it, and move it to Applications. The first time you open it, macOS will warn you. Go to System Settings → Privacy & Security and click Open Anyway. The FAQ explains why.

Questions

Why a terminal command instead of a download button?

Apple charges $99/year to notarize apps. Without that, macOS blocks apps downloaded through a browser behind a warning and a trip to System Settings. Files fetched with curl aren't flagged, so the one-liner installs and opens the app with no warnings. The app itself is still code-signed (ad-hoc), so macOS will notice if anyone tampers with it.

Is it safe to pipe a script into bash?

It's a fair question. Read the script first: it's about 50 lines. It downloads the latest release from GitHub, moves it to Applications, and opens it. It doesn't use sudo and installs nothing else. Everything is open source, and releases are built by GitHub Actions straight from the code.

Does it collect any data?

No. No account, no analytics, no tracking. Its only network request checks GitHub for new versions.

How do I update or uninstall?

Updates: choose Check for Updates… from the menu bar icon, or run the install command again. Uninstall: quit it from the menu and drag OpenLookAway from Applications to the Trash.

Which Macs are supported?

Any Mac on macOS 14 Sonoma or later, Apple Silicon or Intel. It's a native Swift app, not Electron, and it uses almost no CPU or memory.

Is this the official LookAway?

No. It's an independent, open-source project inspired by LookAway, a polished paid app with extras like iPhone sync. If you want those, support the original.
